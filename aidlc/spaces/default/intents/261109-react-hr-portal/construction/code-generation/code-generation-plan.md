## Design choices

Prefer a simple teal/navy staff workspace with directory, employee detail/request panels and assistant chat, responsive to mobile. Reuse functional components and separate services for mocked integration tests. No decorative imagery needed.
Static hosting reuses existing auth; no new runtime, user pool, API data model or secrets. Alternative: public S3 website rejected because private storage and HTTPS are required. Alternative: new agent proxy Lambda rejected unless needed because it adds resource and stream/auth complexity; prefer CloudFront forwarding for browser CORS.
